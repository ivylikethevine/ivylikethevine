## Saffron

![image](images/saffron-heimdall.png?width=750#center 'My current personal homelab dashboard, powered by Saffron.')

An open source, *S*erver as *a* *f*ile *f*older *r*unning *o*n *n*etwork built from docker compose files. I use this as the basis of my personal homelab, and have been developing it since I only had a stack of macbooks for a server rack! For details, [read my full post on it here](/posts/saffron-server-as-a-file-folder-running-on-network/) and the project is available [here](https://github.com/ivylikethevine/saffron)
