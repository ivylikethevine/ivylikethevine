## Introduction

The massive modern adoption of large language models (LLMs, Generative AI, etc.) has happened much faster than other cultural institutions have been able to adapt to. This has led to a type of panic, seeing AI as both a broadcloth replacement of highly skilled engineers and a new, massively unpredictable attack vector. Both of these are shortsided and drastic, and my solution is to view AI agents in a manner similar to how we view interns as part of software development.

This post will not delve into the ethics or morals of AI. If interested, please read my brief AI ethics statement [here](/beliefs/ai-ethics/).

### The "Intern" Model

I say the following as a former software development intern, but an AI agent at this point in time is analogous to a human intern. This is not to demean other interns, past and present, or to imply that AI agents are unskilled. The intern comparison is useful purely as a cognitive model for analysis of software development as a process.

#### Software as a Living System

One of the largest mistakes that non-technical people make when discussing software is to view it as a flat, single point in time. I wish that were true.

Machines aren't alive, but deployed software is a *living, moving, changing thing*. The system is pointless if no one is using it, and if people are using it, it cannot be static. 

## What happened to Best Practices?

In my opinion, the largest issue that the recent influx of AI usage & integration has demonstrated is not an issue with the technology. It is with the **systems** and the **people** that are recklessly, almost thoughtlessly migrating massive portions of infrastructure and development without properly considering the *implications*.

## TL;DR

*AI is powerful and useful, but does not open or expose "new" issues in any system. It does not replace a human developer, and requires a skilled and attentive manager, just like a human intern does. If an intern takes down prod, the issue is not the intern. The manager & the systems above them FAILED to prevent or catch the issue.* 

**_If you would not personally sign off on every single line of AI generated code, then you cannot deploy it._**
